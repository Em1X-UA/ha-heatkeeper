# HeatKeeper для Home Assistant

Розумне керування електричними обігрівачами, які вмикаються через розумні розетки
(on/off). Кожна зона — це одна розетка й один датчик температури. Інтеграція враховує
двозонний тариф і відключення світла. Усі параметри змінюються прямо в UI.

## Встановлення (HACS)

1. HACS → ⋮ → **Custom repositories** → `https://github.com/Em1X-UA/ha-heatkeeper`,
   тип **Integration**.
2. Знайдіть **HeatKeeper** у HACS, встановіть і перезапустіть Home Assistant.
3. **Налаштування → Пристрої та служби → Додати інтеграцію → HeatKeeper**.

## Налаштування

**Крок 1 — джерела даних** (усі поля необовʼязкові):

| Поле | Навіщо |
|---|---|
| Сутність тарифу | Якщо лічильник показує поточну зону тарифу. Вкажіть, які стани означають «дешево» (напр. `T2` або `on`). Якщо поле порожнє, дешева зона визначається за часом (сутності «Початок/Кінець дешевого тарифу»). |
| Датчик наявності мережі | ESP-датчик. Стан `unavailable` теж означає, що світла нема: датчик живиться від мережі. Використовується лише в режимі 3. |
| Денний перемикач | Звичайний `input_boolean` «хтось вдома». HeatKeeper **лише читає** його стан: увімкнено → денна ціль «вдома», вимкнено → «нікого нема». |

**Крок 2 — зони.** Для кожної зони: назва, розетка, датчик температури,
(необовʼязково) датчик вологості. Ставте галочку «Додати ще одну зону», поки не додасте всі.

Згодом зони й джерела можна змінити тут: **HeatKeeper → Налаштувати** (додати, редагувати або видалити зону).

## Режими

Режим вибирається сутністю `select.heatkeeper_mode`.

| Режим | Поведінка |
|---|---|
| **Вимкнено** | Під час перемикання в цей режим HeatKeeper вимикає всі обігрівачі, далі нічого не робить. Разовий нагрів при цьому працює. |
| **1 · Підтримання** | Нагрів вмикається при `t ≤ ціль − дельта` і вимикається при `t ≥ ціль + дельта`. |
| **2 · Двозонний тариф** | Дешева зона: *нічна ціль*. За *N хв до кінця* дешевої зони: *ціль ранкового догріву*. Дорога зона: *денна ціль «вдома»* або *«нікого нема»*, залежно від денного перемикача. |
| **3 · Тариф + відключення** | Те саме, що режим 2, плюс захист від відключень (див. нижче). |

Гістерезис (дельта) спільний для всіх режимів. Кожна зона має **корекцію цілі**
(наприклад, −1 °C для кухні) і перемикач **«Керування увімкнено»**, щоб тимчасово
виключити зону.

### Режим 3: відключення світла

1. Світло зникло (датчик мережі `off` або `unavailable`) → стан **«Нема світла»**,
   нагрів заблоковано.
2. Світло повернулось → HeatKeeper одразу **вимикає всі розетки**: розумні розетки часто
   самі вмикаються після подачі живлення. Далі йде **затримка після відновлення**
   (сенсор «Старт опалення о» показує, коли вона скінчиться).
3. Після затримки:
   - **автовідновлення увімкнено** → зони стартують по черзі з кроком
     *«Інтервал між зонами»*, щоб не вмикати все одночасно. Кожна зона гріється до
     *«Цілі після відключення»*, а потім переходить у звичайне підтримання режиму 2.
     Значення `0` означає «без окремого догріву»;
   - **автовідновлення вимкнено** → стан **«Пауза»**, доки не натиснете
     **«Відновити опалення»**. Цю кнопку можна натиснути й під час затримки,
     щоб її пропустити.

Після перезапуску HA перші 90 с недоступний датчик мережі не вважається відключенням,
бо ESPHome потребує часу на підключення.

### Разовий нагрів

Кнопка **«Разовий нагрів»** (загальна або окремо для зони) гріє до *«Цілі разового
нагріву»* і вимикає обігрівач. Після цього керування повертається до поточного режиму
(у режимі «Вимкнено» обігрівач так і лишиться вимкненим). **«Скасувати разовий нагрів»**
зупиняє нагрів.

## Дашборд

Готовий дашборд лежить у [`dashboards/heatkeeper.yaml`](dashboards/heatkeeper.yaml).
Він показує лише ті параметри, які стосуються вибраного режиму. Як додати:
**Налаштування → Дашборди → Додати дашборд → З нуля**, потім ⋮ → Редагувати → ⋮ →
Редактор сирої конфігурації, і вставте вміст файлу. Замініть назви зон і
`input_boolean.heating_home` на свої.

Entity id не залежать від мови інтерфейсу:
`select.heatkeeper_mode`, `number.heatkeeper_<параметр>`,
`sensor.heatkeeper_<зона>_zone_status`, де `<зона>` — транслітерована назва
(Вітальня → `vitalnia`, Кухня → `kukhnia`).

## Приклади автоматизацій

Про телефон і кнопку інтеграція не знає. Звʼязок із ними налаштовується окремими автоматизаціями.

**Присутність телефону → денний перемикач:**

```yaml
automation:
  - alias: Опалення — хтось вдома
    triggers:
      - trigger: state
        entity_id: person.me
    actions:
      - action: >-
          input_boolean.turn_{{ 'on' if trigger.to_state.state == 'home' else 'off' }}
        target:
          entity_id: input_boolean.heating_home
```

**Zigbee-кнопка → разовий нагрів** (приклад для Zigbee2MQTT, події `single`):

```yaml
automation:
  - alias: Опалення — кнопка разового нагріву
    triggers:
      - trigger: state
        entity_id: event.heating_button_action
        attribute: event_type
        to: single
    actions:
      - action: button.press
        target:
          entity_id: button.heatkeeper_boost
```

## Сутності

| Сутність | Опис |
|---|---|
| `select.heatkeeper_mode` | Режим |
| `sensor.heatkeeper_status` | Що зараз відбувається (ніч, догрів, день, нема світла, …) |
| `binary_sensor.heatkeeper_cheap_tariff` | Дешевий тариф активний |
| `binary_sensor.heatkeeper_grid` | Мережа (як її бачить HeatKeeper) |
| `sensor.heatkeeper_restore_at` | Коли почнеться нагрів після відновлення світла |
| `number.heatkeeper_maintain_target`, `…_delta` | Режим 1 |
| `number.heatkeeper_night_target`, `…_preheat_target`, `…_preheat_lead` | Ніч і ранковий догрів |
| `number.heatkeeper_day_home_target`, `…_day_away_target` | День |
| `time.heatkeeper_cheap_start`, `…_cheap_end` | Межі дешевої зони |
| `number.heatkeeper_boost_target`, `button.heatkeeper_boost`, `…_boost_cancel` | Разовий нагрів |
| `number.heatkeeper_outage_target`, `…_restore_delay`, `…_restore_stagger`, `switch.heatkeeper_auto_restore`, `button.heatkeeper_resume` | Режим 3 |
| `sensor.heatkeeper_<зона>_zone_status`, `…_zone_target`, `switch.heatkeeper_<зона>_enabled`, `number.heatkeeper_<зона>_offset`, `button.heatkeeper_<зона>_boost` | Зони |

Налаштування зберігаються між перезапусками HA.

## Безпека

- Якщо датчик температури недоступний, обігрівач зони вимикається: наосліп інтеграція не гріє.
- Якщо розетка недоступна, команди їй не надсилаються.
